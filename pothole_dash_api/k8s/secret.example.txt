Ne pas committer de vrai secret dans le repo (la cle Gemini vit deja dans
.env, qui est gitignore - ne la recopie pas dans un fichier verse au repo).
Cree le Secret directement dans le cluster :

  kubectl create secret generic pothole-dash-api-secret \
    --namespace parkey \
    --from-literal=GEMINI_API_KEY='ta-cle-gemini'

Pour la mettre a jour plus tard :

  kubectl delete secret pothole-dash-api-secret -n parkey
  kubectl create secret generic pothole-dash-api-secret -n parkey --from-literal=GEMINI_API_KEY='...'
