Ne pas committer de vrai secret dans le repo. Cree le Secret directement
dans le cluster avec kubectl (rien n'est ecrit sur disque ni versionne) :

  kubectl create secret generic pothole-spring-api-secret \
    --namespace parkey \
    --from-literal=JWT_SECRET='change-moi-min-32-caracteres!!' \
    --from-literal=SMTP_USER='' \
    --from-literal=SMTP_PASS=''

Pour mettre a jour plus tard :

  kubectl delete secret pothole-spring-api-secret -n parkey
  kubectl create secret generic pothole-spring-api-secret -n parkey --from-literal=...

Structure equivalente en YAML (a titre indicatif seulement - ne pas
appliquer avec ces valeurs) :

  apiVersion: v1
  kind: Secret
  metadata:
    name: pothole-spring-api-secret
    namespace: parkey
  type: Opaque
  stringData:
    JWT_SECRET: "change-moi-min-32-caracteres!!"
    SMTP_USER: ""
    SMTP_PASS: ""
